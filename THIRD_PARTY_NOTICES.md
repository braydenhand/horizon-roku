## Design inspiration

The visual language (photo first, a single glass dock, white marks, a gliding focus plate, pre‑rendered glass materials) follows [CleanFrame](https://github.com/nthnclrk/CleanFrame) (MIT), a launcher for Samsung's Frame TVs. No CleanFrame code is used; Horizon is a separate implementation for Roku.
